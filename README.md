# SplitWise — Neumorphic Soft UI Expense Splitter & Debt Settlement

A modern, tactile, Soft UI Neumorphic web application for group expense splitting, receipt itemization, trip budget management, and intelligent debt simplification.

![SplitWise Soft UI](public/app-icon.png)

---

## ✨ Features

- **360° Turntable Selection Dial**:
  - Interactive radial wheel for navigating services with continuous momentum, flick/swipe gestures, and keyboard navigation.
- **Smart Splitting Services**:
  - **Equal Split**: Instantly split bills and custom tips across any number of people with penny-accurate rounding.
  - **Items Split**: Add receipt items with prices, tax, tips, and assign individual consumption per person with automatic breakdown calculations.
  - **Trip Split**: Manage multi-currency trip budgets, group members, categorized trip logs, and view debt settlements.
- **Greedy Debt Simplification Algorithm**:
  - Minimizes total settlement transactions between group members using an optimized balance-matching algorithm.
- **Tactile Neumorphism (Soft UI)**:
  - Dual opposing extruded and inset shadow system with curated light and dark theme palettes.
  - Smooth micro-interactions and transitions.
- **Client-Side Privacy & Export**:
  - 100% private local storage persistence.
  - Export and import workspace backups as JSON.
  - Professional PDF statement generation.
- **Fully Responsive**:
  - Seamlessly adapts across mobile, tablet, and desktop viewports.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/sujithkumar09042005-a11y/SplitWise.git

# Navigate to project directory
cd SplitWise

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Running Tests

```bash
npm test
```

### Building for Production

```bash
npm run build
```
